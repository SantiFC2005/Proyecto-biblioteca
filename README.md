# Proyecto-biblioteca

proyecto final de ingenieria de software uniliversidad libre 2026 para el desarrollo de la Propuesta 5. Biblioteca o préstamo de recursos
Control de préstamos de libros, equipos u otros recursos.
•	Varios tipos de recurso con reglas de préstamo diferentes (plazo, cantidad máxima, renovaciones).
•	Varios tipos de usuario (estudiante, docente, externo) con privilegios distintos.
•	Cálculo de multas con políticas intercambiables.
•	Lista de espera: avisar al siguiente usuario cuando un recurso queda disponible.
•	Un catálogo único y consistente en toda la aplicación.
•	Reportes de uso y de recursos más solicitados.
